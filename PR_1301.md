## Summary

Closes #1301

`DidModule`/`DidService` previously had no TypeORM entity: generated W3C DID documents were returned to callers but never stored, so they were lost on restart. This PR adds a real `did_document` table, repository-backed CRUD in `DidService`, and REST endpoints.

## Changes

- **Entity** `backend/src/did/entities/did-document.entity.ts` — `did_document` with `id` (uuid PK), `did` (unique + index), `document` (jsonb), `controller` (uuid FK → `users.id`, indexed), `created_at`, `updated_at`, `deactivated_at` (delete-date column used for soft-delete/deactivation).
- **Migration** `backend/src/database/migrations/2230000000000-CreateDidDocuments.ts` — creates the table, `UQ_did_document_did`, `FK_did_document_controller ... ON DELETE CASCADE`, indexes `IDX_did_document_did` / `IDX_did_document_controller`; reversible `down()`. Timestamp `2230000000000` is unique and sorts last.
- **Module** `backend/src/did/did.module.ts` — `TypeOrmModule.forFeature([DidDocument])`.
- **Service** `backend/src/did/did.service.ts` — injects `Repository<DidDocument>`; `createDid`/`getDid`/`updateDid`/`deactivateDid` (plus `*DidDocument` aliases) replace in-memory storage for DID documents, with duplicate-DID, not-found and controller-ownership checks. Deactivation uses `softDelete()` which fills `deactivated_at`.
- **DTOs** — `CreateDidDocumentDto`, `UpdateDidDocumentDto`.
- **Controller** — `POST /v1/did`, `GET /v1/did/:did`, `PUT /v1/did/:did`, `DELETE /v1/did/:did` (JWT-guarded, controller taken from `@CurrentUser`); existing credential endpoints unchanged.
- **Tests** — extended `did.service.spec.ts` with repository mock and 5 CRUD/regression cases; added `did.controller.spec.ts` (2 cases).
